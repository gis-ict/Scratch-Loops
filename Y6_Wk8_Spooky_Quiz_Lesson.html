Variables: score and lives

A variable is a labelled box. The label stays the same. The value inside changes.

1. Make the boxes

Variables (orange) → Make a Variable → type score. Do it again for lives.

score 0lives 3

2. Start every game fresh

when green flag clicked set score to 0 set lives to 3

Forget this and the score starts from the old game.

3. Change the value

change score by 1 change lives by -1

set = replace the value. change = add to it.

Predict first

7 min

User input: ask and answer

User input = the player types something and the program uses it.

1. Ask

ask What is your name? and wait

A box appears. The game waits until the player presses Enter.

2. Answer

answer

Scratch puts what they typed into answer. It is a variable Scratch made for you. It only keeps the newest answer.

3. Use it

say join Welcome, answer for 2 seconds

join (green, Operators) glues two pieces of text together.

4. Check the answer: if then else

ask How many legs does a spider have? and wait if answer = 8 then
change score by 1 say Correct! for 1 seconds
else
change lives by -1 say Wrong! for 1 seconds

Input → the player types.
Variable → answer, score, lives.
Branch → if then else picks one path.

Tip: use questions with number answers or one-word answers. "eight" is not the same as "8".

Teacher notes Demo live in Scratch: ask a student's name and say it back. Show that Scratch ignores capital letters (Ghost = ghost) but not spelling.
